# Utilitários Municipais — v4.3.5

Versão para testes do novo módulo **Datas**.

## Adicionado

- Operação padrão **Contador de dias entre datas**.
- Operações **Somar Dias em Datas** e **Subtrair Dias em Datas**.
- Campos de data com calendário nativo do navegador.
- Campo de quantidade de dias mostrado apenas quando necessário.
- Validação de data inicial, data final, ordem cronológica e quantidade inteira não negativa.
- Resultado em painel destacado.
- Informação complementar em semanas e dias no contador.
- Botões **Copiar resultado** e **Limpar**.
- Integração do módulo à navegação, pesquisa global e Biblioteca de ferramentas.

## Corrigido

- Removido definitivamente o texto literal `\n` exibido abaixo do campo **Descrição** em Calculadora UVRM > Novo Lançamento, preservando o histórico/autopreenchimento.

## Banco de dados

Nenhuma alteração de schema. Não é necessário executar novo SQL para a versão 4.3.5.
