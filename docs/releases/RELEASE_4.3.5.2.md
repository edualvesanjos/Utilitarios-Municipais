# Utilitários Municipais — v4.3.5.2

Hotfix de Configurações.

## Corrigido

- **Cor principal:** adicionado botão **Aplicar** ao lado da seleção de cor.
- A cor selecionada somente é gravada/aplicada ao clicar em **Aplicar**.
- Após a aplicação é exibida a mensagem **“Cor aplicada com sucesso!”**.
- A preferência continua sendo persistida junto às demais configurações de interface.
- **Conta e gerenciamento de sincronização:** botões **Entrar ou criar conta**, **Sincronizar agora**, **Usar dados online** e **Sair** organizados horizontalmente e com altura uniforme em telas de desktop.
- Em telas menores, os botões podem quebrar de linha para preservar a legibilidade.

## Banco de dados

Nenhuma alteração de schema. Não é necessário executar novo SQL.
