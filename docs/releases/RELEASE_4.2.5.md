# Utilitários Municipais — versão 4.2.5

## Correção aplicada

A aba **Configurações** foi ajustada para utilizar toda a largura disponível da página. O layout anterior preservava a grade de duas colunas usada por outros módulos, deixando uma área vazia à direita quando os painéis auxiliares não ocupavam a segunda coluna.

### Resultado

- painel de personalização e sincronização em largura integral;
- cartões auxiliares posicionados abaixo do conteúdo principal;
- comportamento responsivo em telas menores;
- nenhuma alteração na lógica de sincronização ou nos dados existentes.
