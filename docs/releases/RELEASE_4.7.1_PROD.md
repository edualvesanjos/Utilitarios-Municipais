# Utilitários Municipais v4.7.1 PROD

## Escopo

Publicação em produção da recuperação de senha homologada na v4.7.1.2 DEV.

## Recuperação de senha

- Solicitação: `POST /auth/v1/password/forgot`.
- Redefinição: `POST /auth/v1/password/reset`.
- URL de retorno PROD: `https://edualvesanjos.github.io/Utilitarios-Municipais/`.
- Mantém o isolamento dos dados antes do login.

## Banco de dados

Nenhuma alteração de schema ou SQL é necessária nesta versão.
