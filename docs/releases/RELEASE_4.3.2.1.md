# Utilitários Municipais — v4.3.2.1

Hotfix funcional da Calculadora UVRM.

## Calculadora UVRM

O campo **Descrição** de **Novo Lançamento** passa a oferecer autopreenchimento com descrições utilizadas anteriormente.

As descrições são armazenadas somente quando um lançamento válido é adicionado ou atualizado, evitando registrar textos incompletos digitados durante o preenchimento. O histórico é local, elimina duplicidades equivalentes e mantém as 30 descrições mais recentes.

## Banco de dados

Nenhuma alteração no schema. Não é necessário executar novo SQL no Supabase.
